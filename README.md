# Customer Churn & Retention Analytics

## Project Overview

This project analyzes customer churn behavior using SQL, Python,
statistical analysis, machine learning, and Power BI.

The objective is to identify customer behaviors and segments
associated with churn, develop a predictive churn model, and
translate analytical findings into actionable retention insights.

## Business Problem

Customer churn can reduce recurring revenue and customer lifetime value.

This project investigates:

- What percentage of customers churn?
- Which customer characteristics are associated with churn?
- Which customer segments have elevated observed churn rates?
- Can customer churn be predicted using machine learning?
- Which customers have higher predicted churn risk?
- What retention actions could be considered based on the findings?

## Dataset

The dataset contains 3,333 telecom customers and 11 variables
covering customer tenure, contract renewal, data usage,
customer service interactions, calling behavior, charges,
roaming activity, and churn status.
